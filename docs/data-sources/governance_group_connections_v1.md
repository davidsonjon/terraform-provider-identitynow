# identitynow_governance_group_connections_v1 (Data Source)

Lists the objects (roles, access profiles, SOD policies, sources) connected to a [Governance Group](https://documentation.sailpoint.com/saas/help/common/governance_groups.html) via `GET /workgroups/v1/{workgroupId}/connections`. Connections are read-only here - they are established from the referencing object's own configuration (e.g. a role naming this governance group as an owner), not from the governance group side.

~> This is a `_v1` pilot data source.

## Example Usage

```terraform
# Lists the objects (roles, access profiles, SOD policies, sources)
# connected to a governance group as owner/reviewer.
data "identitynow_governance_group_connections_v1" "example" {
  governance_group_id = "2c91808a7813090a017814121919ecca"
}

output "example_connection_object_ids" {
  value = [for c in data.identitynow_governance_group_connections_v1.example.connections : c.object_id]
}
```

## Known Limitations & Live Testing Notes

See the [`identitynow_governance_group_v1` resource documentation](../resources/governance_group_v1.md#known-limitations--live-testing-notes)
for background on the pilot status shared by all Governance Group targets.

Connections returned here are read-only reflections of the *referencing*
object's own configuration (e.g. a role naming this governance group as an
`Owner`) - there is no way to create or remove a connection from the
governance group side; manage the referencing resource instead.

# identitynow_access_model_metadata_attribute_v1 (Data Source)

Reads an [Access Model Metadata](https://documentation.sailpoint.com/saas/help/access/metadata.html) Attribute from IdentityNow/ISC by `key`.

~> This is a `_v1` pilot data source - see the resource documentation's "Known Limitations & Live Testing Notes" section before relying on it in production configurations.

## Example Usage

```terraform
data "identitynow_access_model_metadata_attribute_v1" "example" {
  key = "exampleDataClassification"
}
```

# identitynow_applications_v1 (Data Source)

Lists Applications (source apps) from IdentityNow/ISC via `GET /source-apps/v1/all`, optionally filtered, sorted, and paginated. Returns the same attributes per application as the singular `identitynow_application_v1` data source, including `access_profile_ids`.

## Example Usage

```terraform
# Lists applications (source apps) whose name starts with "Engineering",
# capped at 10 results. Each entry in `applications` has the same attributes
# as identitynow_application_v1, including access_profile_ids.
data "identitynow_applications_v1" "example" {
  filters = "name sw \"Engineering\""
  limit   = 10
}

output "engineering_application_ids" {
  value = [for a in data.identitynow_applications_v1.example.applications : a.id]
}
```

## Known Limitations & Live Testing Notes

Each entry in `applications` is populated by the same conversion code as the
singular [`identitynow_application_v1` data source](../data-sources/application_v1.md) -
see its "Known Limitations & Live Testing Notes" section for details,
including how `access_profile_ids` is populated via a separate API call per
application.

The API's documented maximum `limit` for `GET /source-apps/v1/all` is 250;
requested limits above that are capped with a warning rather than an error.
